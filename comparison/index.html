Сначала готовые профили — затем выбор команды

Версия 0.2.0-candidate.1 · ktlint 1.8.0 · кандидат для обсуждения.

A — стиль по эталону. Оформление на основе разобранных шаблонов с явно выбранными нормами: 140 символов, параметры объявлений с четырёх — столбиком, Modifier с двух вызовов, без последних запятых, пустая строка после многострочной ветки when. Компактные вложенные лямбды сохраняются; короткий intent — до 120. Это конкретное предложение по эталону: там, где исходники различаются, мы выбрали один вариант.
B — штатный ktlint_official. Лимит 120 задан явно для сравнения. Применяются штатные правила оформления; наши восемь правил отключены. Это поддерживаемый вариант ktlint, а не заявление о единственно правильном стиле или точном совпадении с Google Style.

Два стиля Kotlin на примерах

Слева — предложение по эталону. Справа — стандартный стиль ktlint. Ниже коротко написано, на что смотреть; жёлтым выделены отличающиеся строки. Профили показывают результат целиком — отдельные настройки выбираем в анкете.

Перейти к анкете: 10 вопросов

По эталону: лимит 140, Modifier с двух вызовов, параметры объявлений с четырёх — столбиком, без последних запятых; короткий intent до 120 собирается в строку.
Стандартный ktlint: профиль ktlint_official, для сравнения выбран лимит 120; наши дополнительные правила выключены.

Это два кандидата для обсуждения. Название стандартного профиля не означает, что он единственно правильный или точно повторяет Google Style. Все примеры учебные.

Modifier: цепочка в строку или столбиком

В первом варианте перенос начинается с двух вызовов Modifier. Во втором на этом примере цепочка остаётся в строку.

По эталону

import androidx.compose.ui.Modifier fun card(modifier: Modifier) {    val objectChain = Modifier        .fillMaxSize()        .padding(8)    val parameterChain = modifier        .fillMaxSize()        .padding(8)    val normalizedText = text.trim().lowercase()}

Стандартный ktlint

import androidx.compose.ui.Modifier fun card(modifier: Modifier) {    val objectChain = Modifier.fillMaxSize().padding(8)    val parameterChain = modifier.fillMaxSize().padding(8)    val normalizedText = text.trim().lowercase()}

Последняя запятая в вызове

В одном профиле последняя запятая убирается, в другом добавляется. На этом же примере видна разница вложенной лямбды.

По эталону

fun card() {    renderCard(        title = title,        count = count,        onClick = onClick    )} fun event() {    Analytics.send(Event("click") {        putString("target", target)    })}

Стандартный ktlint

fun card() {    renderCard(        title = title,        count = count,        onClick = onClick,    )} fun event() {    Analytics.send(        Event("click") {            putString("target", target)        },    )}

Исходный пример

Пустые строки в when

По эталону пустая строка отделяет большую ветку. Короткие ветки идут рядом.

По эталону

Стандартный ktlint

fun handle(event: Event) {    when (event) {        Event.Open -> {            closeKeyboard()            openDetails()        }         Event.Back -> {            goBack()        }         Event.Refresh -> {            refresh()        }         Event.Close -> {            close()        }    }}

21 вопрос, 23 сравнения. Исходный А извлечён из сохранённого файла без замены имён и логики. Б получен форматированием копии полного файла. Правила: экспериментальный JAR 0.4.0-ballot.1, ktlint 1.8.0.

Для обеих сторон на 23 полных копиях выполнены format → repeat → check. 23 показанных фрагмента А восстановлены из Б точно; повтор стабильный, check без замечаний. Значимые токены сверены с разрешёнными изменениями оформления: запятые, пустые () перед trailing lambda и порядок импортов.

46 сравнений CLI с реальным загрузчиком и движком IDE совпали. Это проверка движка, а не ручного шортката Studio. Android-сборка не выполнялась. Полный файл А не обязан побайтно совпасть с историческим оригиналом вне выбранного фрагмента.

Каждая пара проверена отдельно. Итоговый профиль после голосования нужно проверить целиком. Предыдущая проверка 16 сочетаний наследования показала перекрёстные изменения в 6 сочетаниях: стабильность не гарантирует независимость настроек.

Общий предел — 140 символов. У data class отдельный порог 3; у обычного класса — 4. Для вопроса о пробеле перед двоеточием обе стороны сохраняют первое наследование рядом с объявлением. В вопросе импортов используется настоящий пакет исходника.

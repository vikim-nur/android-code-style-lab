# Покрытие исходных наблюдений кандидатом A

Статус: предложение для review. 23 наблюдения не превращаются в 23 гарантии единственного результата любого Kotlin-ввода. Ниже явно различены автоисправление, допустимый диапазон и выбранные новые нормы.

| ID | Область | Реализованный контракт | Механизм/ограничение |
|---|---|---|---|
| N01 | Отступ | Нормализуется | standard:indent, четыре пробела |
| N02 | Modifier-цепочки | Нормализуется для распознанных форм | nur:modifier-chain, от2; без type resolution |
| N03 | Обычная короткая цепочка | Допускается компактный вид | Глобальный force-порог цепочек отключён; другие правила и ширина действуют |
| N04 | Аргументы многострочного вызова | Нормализуется | standard:argument-list-wrapping |
| N05 | Большие вызовы | Нормализуется | Исключение9+ отключено через unset |
| N06 | Короткий вызов | Допускается одна строка | nur:call-arguments выключен; принудительного схлопывания всех вызовов нет |
| N07 | Параметры функции4+ | Нормализуется | Штатный force-порог4; это наш явный порог, не доказанная историческая причина |
| N08 | Короткая многострочная сигнатура | Допустимый диапазон | Не обещаем автоматическое схлопывание всех коротких объявлений |
| N09 | Конструктор4+ | Нормализуется | Штатный class-signature threshold4 |
| N10 | Запятая вызова | Нормализуется без последней запятой | nur:call-site-comma, делегирование ktlint1.8 |
| N11 | Запятая объявления | Нормализуется без последней запятой | nur:declaration-site-comma; распространено и на другие declaration sites |
| N12 | Expression body рядом с = | Поддерживается | function_signature_body_expression_wrapping=default |
| N13 | Короткая лямбда/intent | Узкое автоисправление | Компактный intent<=120 только single statement/no comments; inline обратно не разворачивается |
| N14 | Скобки короткой ветки when | Допустимый диапазон | when-entry-bracing отключён; не удаляет уже написанные скобки |
| N15 | Пустая строка после большой ветки | Нормализуется в проверенной области | nur:when-branch-spacing; не переставляет комментарии/неоднозначные separators |
| N16 | Аннотация DTO | Поддерживается штатным правилом | Разные допустимые позиции annotation не сводятся автоматически к одной новой норме |
| N17 | Импорты | Нормализуется | *,java.**,javax.**,kotlin.**,^; naming/unused/wildcard не включены в этот форматирующий опыт |
| N18 | Длина строки | Проверяется, не всё исправляется | 140 как наше предложение;4замечания остались в567файлах |
| N19 | Особый if без скобок | Допустимый диапазон | Сохраняется допустимый ручной вид; не семантический pretty-printer любого if |
| N20 | Пустая первая строка функции | Явное отклонение для единого кандидата | В A лишняя первая строка удаляется стандартным правилом |
| N21 | Конец файла | Нормализуется | Один завершающий перевод строки; в источниках соблюдался не везде |
| N25 | Двоеточие наследования | Нормализуется штатным правилом | class Sample : Base(); custom type-colon-spacing выключен |
| N26 | Внешние скобки вложенной лямбды | Компактный шаблон поддерживается | nur:nested-lambda-wrapping сохраняет допустимый компактный вид; не общее схлопывание любого expanded input |

Требование наследовать конкретный тип, UI State mutability и DI не входят в форматирование. Внешний вид адаптеров/наследования показан в F04/F05/F10 examples, а не заявлен отдельным архитектурным правилом.

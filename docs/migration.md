# Перенос в корпоративный Git

Личный публичный репозиторий vikim-nur/android-code-style-lab — место подготовки, без подключения к приложениям.

После согласования создать целевой корпоративный репозиторий, перенести Git-историю main и выбранные теги, проверить видимость/доступы и назначить его единственным источником дальнейших выпусков. В потребителях изменить URL и закрепить точную версию; прогнать отдельный пилот. Старую личную копию обозначить архивом, чтобы не появилось два источника правил.

Код общих инструментов и история не зависят от домена хостинга. Package/group/plugin ID пока экспериментальные. Их изменение, если потребуется, планируется отдельно. Никакого автоматического обновления всех приложений из одной смены URL нет.

В текущем репозитории нет рабочих снимков приложений, внутренних URL, доступов или исходных корпоративных фрагментов. Перенос в компанию и подключение приложений требуют отдельного согласования.

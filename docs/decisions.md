# Решения

Все правила пока предложены. Ответы команды, второй review и утверждение ожидаются.

Для каждого принятого пункта записываем: решение, причину, исключения, точную версию профиля, подтверждение принимающего и дату.

Порядок: обсудить оформление → проверить выбранную комбинацию → согласовать → разрешить отдельный пилот → измерить и сделать вывод. Статический анализ обсуждается отдельно.

Не считать пустые ответы согласием. Голосование отражает предпочтения, но не заменяет техническую проверку совместимости.

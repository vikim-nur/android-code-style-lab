# Предлагаемый стиль Kotlin

Статус: предложение для обсуждения, не командный стандарт.

- ktlint 1.8.0, android_studio как исходный профиль; четыре пробела.
- Предлагаемый лимит 140 символов; длинные литералы и комментарии не всегда исправляются автоматически.
- Объявления функций и конструкторов с 4+ параметрами — многострочные.
- Число аргументов вызова само по себе не требует переноса.
- В уже многострочных вызовах каждый аргумент — отдельно, включая большие вызовы.
- Распознанные Modifier-цепочки с двух вызовов — по вызову на строку.
- Короткие обычные цепочки могут оставаться в строку.
- Завершающие запятые сохраняются в обоих допустимых видах.
- Пустые строки when пока оставлены автору.
- Короткий intent без комментариев с одним выражением может собираться в строку до 120 символов.
- Пробелы у типов и наследования нормализует штатный colon-spacing.
- Группы java/javax/kotlin — в конце импортов, alias после них.

Точный профиль — ../config/formatting.proposed.editorconfig. Ему необходим JAR наших правил. Параметры анкеты сравниваются по одному поверх экспериментального исходного профиля. После выбора команды комбинацию нужно проверить целиком. Учебные Kotlin-фрагменты проверены форматтером, не компиляцией Android-приложения.

Штатный wrapping выключен ради нашей замены вложенных лямбд. Строгие правила trailing comma требуют именно штатный wrapping: в соответствующих вариантах анкеты замена выключена. Это ограничение текущей реализации, а не невозможность дальнейшей доработки.

Предлагаемый профиль пока отдельный: в ресурсах транспортного прототипа лежит прежний тестовый профиль. Не подменять его незаметно до согласования и повторной проверки Studio.
